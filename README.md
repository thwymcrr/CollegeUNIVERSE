# CollegeUNIVERSE 🎓

CollegeUNIVERSE is a college fest website designed to provide students with information about college events, special performances, departments, admissions, placements, and festival activities.

## 🚀 Features

- Responsive college fest website
- Interactive navigation bar
- Smooth scrolling between sections
- College fest event banner
- Artist showcase section
- Interactive artist image viewer
- Festival gallery with image preview
- Scroll reveal animations
- Active navigation highlighting
- Back-to-top button
- Toast notifications
- Keyboard shortcuts
- Interactive footer elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Remix Icon
